### A. 회귀 0 확인 (옵션 OFF 상태 — 가장 중요)

**조작**
1. 앱을 새로 실행한다 (설정을 건드리지 않은 상태 = `UsePatternBrushMask` 꺼짐)
2. 평소처럼 Datum 티칭 화면에서 [패턴 1] 로 ROI 를 그리고 [패턴 모델 생성] 을 누른다
3. Bottom 비전 화면에서 슬롯을 고르고 ROI 2개를 그린 뒤 [티칭 저장] 을 누른다

**PASS 이면**
- 두 경우 모두 **기존과 똑같은 메시지/점수/모달**이 뜬다
- 화면 어디에도 빨간 반투명 자국이 없다

**중단해야 하면**
- 예전에 없던 오류·팝업·점수 급락이 생긴다
- 칠하지도 않았는데 빨간 자국이 보인다
- 티칭 점수가 눈에 띄게 떨어진다


### B. Bottom Align 브러시 칠하기 (이 기능의 본래 목적)

**조작**
1. Bottom 비전 화면을 연다
2. [Grab] 또는 [폴더 열기] 로 이미지를 띄운다
3. 면 슬롯을 고른다
4. [ROI 1] / [ROI 2] 로 패턴 ROI 두 개를 그리고 [티칭 저장] 을 눌러 기준 모델을 먼저 만든다
5. "브러시 마스킹" 패널에서 **[브러시 마스킹 사용]** 을 체크한다
6. **[칠하기 모드]** 를 누른다
7. 굵기 슬라이더를 적당히(예: 30px) 맞춘다
8. ROI 안의 노이즈/반사/이물 위를 **마우스 왼쪽 버튼을 누른 채 끌어서** 칠한다
9. 마우스 버튼을 **놓는다**

**PASS 이면**
- 끄는 동안 지나간 자리가 **빨간 반투명**으로 즉시 칠해진다 (붓처럼 이어져야 한다 — 점이 뚝뚝 끊기면 안 된다)
- 포인터를 따라 **노란 원**(브러시 크기 미리보기)이 움직인다
- 마우스를 놓은 직후 패널 상태 문구가 **"마스크 반영 + 모델 재생성 완료 (2개 경로)"** 로 바뀐다
- 그 자리에서 [검사] 를 눌러도 매칭이 여전히 성공한다

**중단해야 하면**
- 칠했는데 화면에 아무것도 안 보인다 → **HALCON 색상/알파 문제**. 중단하고 알려 주시라
- 자국이 화면 위에 그려지다가 스크롤·확대하면 사라지거나 어긋난다
- 마우스를 놓을 때마다 팝업이 뜬다 (모달 금지 위반)
- 상태 문구가 "마스크 저장 실패" 로 나온다 → 문구 전문을 알려 주시라
- 자국 하나 칠할 때마다 화면이 몇 초씩 멈춘다 (재생성이 자국마다 도는 것)


### C. 마스크가 남아 있는지 (저장/복원)

**조작**
1. B 를 끝낸 뒤 다른 면 슬롯으로 바꿨다가 다시 원래 슬롯으로 돌아온다
2. 앱을 껐다가 다시 켜고 같은 슬롯을 고른다
3. 탐색기로 레시피 폴더의 `EthernetAlign`(또는 모델이 있는 폴더)을 연다

**PASS 이면**
- 슬롯을 돌아오면 아까 칠한 빨간 자국이 **그대로 다시 뜬다**
- 앱을 다시 켜도 마찬가지다
- 폴더 안에 `Bottom_XXX_1.shm` 옆에 `Bottom_XXX_1.mask.hobj` 가 **같은 폴더**에 있다

**중단해야 하면**
- 마스크 파일이 **엉뚱한 폴더**(예: 새로 생긴 빈 폴더)에 있다 → Phase 73 과 같은 경로 사고. 즉시 중단
- 슬롯을 돌아왔더니 **다른 슬롯의 자국**이 뜬다
- 앱 재실행 후 자국이 사라진다


### D. 지우개 · 마스크 초기화

**조작**
1. [지우개] 를 누르고 칠한 자국의 일부를 문질러 지운다
2. [칠하기 모드] 로 돌아와 다시 조금 칠한다
3. [마스크 초기화] 를 누른다

**PASS 이면**
- 지우개로 문지른 부분만 사라지고, 놓을 때마다 상태 문구가 갱신된다
- [마스크 초기화] 후 자국이 전부 사라지고 상태 문구가 **"마스크 초기화 완료 (파일 N개 삭제)"** 로 나온다
- 탐색기에서 `.mask.hobj` 파일이 **실제로 사라져 있다**(고아 없음)

**중단해야 하면**
- 초기화했는데 파일이 남아 있다
- 초기화 후에도 모델이 여전히 마스크를 반영한 상태다


### E. Datum 티칭 화면 브러시

**조작**
1. 검사 메인 화면에서 Datum 티칭 존을 하나 고른다
2. [패턴 1] 로 ROI 를 그리고 [패턴 모델 생성] 으로 기준 모델을 만든다
3. 툴바의 **[브러시]** 를 누른다 → 툴바 아래에 패널이 펼쳐진다
4. [브러시 마스킹 사용] 체크 → [칠하기 모드] → ROI 안을 칠한다 → 놓는다
5. 다른 Datum 을 클릭했다가 돌아온다

**PASS 이면**
- 패널이 **툴바 아래**(이미지 창 밖)에 펼쳐진다 — 이미지 위에 겹쳐서 잘리면 안 된다
- 칠하고 놓으면 상단 힌트 라벨에 **"마스크 반영 모델 재생성 완료 — 종료 전 Recipe Save 필요"** 가 뜬다
- 다른 Datum 으로 갔다 돌아오면 그 Datum 의 마스크가 다시 뜬다
- **[Recipe Save] 를 눌러 저장한다** (모델 파일은 바로 저장되지만 기준 좌표는 메모리라 저장이 필요하다)

**중단해야 하면**
- 패널이 이미지 창에 가려서 안 보인다 → airspace 문제. 중단
- Datum 을 바꿨는데 이전 Datum 의 마스크가 남아 있다
- 툴바 버튼 배치가 어긋났다
