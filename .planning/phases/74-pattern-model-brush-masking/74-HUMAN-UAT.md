## 무엇을 만들었나

Shape/NCC 패턴 모델을 만들 때 원하지 않는 영역을 브러시로 칠해 제외하는 **옵션 기능**.

- 마스크는 모델 파일(`.shm`/`.ncm`) 옆에 `같은이름.mask.hobj` 로 저장된다
- 적용 지점은 `PatternMatchService.TryCreateModel` **한 곳** — Bottom Align · Tray Align · Datum 티칭 자동 적용
- 칠하기를 끝내는 순간(마우스 놓기) 모델이 자동으로 다시 만들어진다
- 브러시 자국은 HALCON 창 **안**에 반투명 빨강. 컨트롤은 창 **밖** 사이드 패널
- **설정의 `UsePatternBrushMask` 가 꺼져 있으면(기본값) 마스크 파일이 있어도 무시된다**

**의도한 사용 순서 (사용자 확인 완료):** ROI 그리기 → 브러시로 뺄 부분 칠하기 → 마우스 놓기 →
마스크 저장 → 자동 재티칭 → **ROI − 마스크 영역으로 모델 등록**.
마스크 경로는 모델 파일 존재 여부와 무관하게 계산되므로 **등록 전에 칠해도 된다.**

**ROI 밖에 칠한 자국:** 자유롭게 칠할 수 있고 ROI 밖은 모델에 영향이 없다(사용자 결정).
화면에는 ROI 밖 자국도 보인다 — 정상이다.
