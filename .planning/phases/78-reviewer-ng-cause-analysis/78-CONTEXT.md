# Phase 78 — CONTEXT (결정 2026-09-17)

**목적 (사용자 원문): "NG가 나면 왜 나는지 분석이 필요함이 목적"**

결과 리뷰어에서 NG 가 나면 **왜 났는지 규칙으로 자동 추정**해서, 비전을 모르는 운영자도
"무슨 문제인지 / 무엇을 확인하면 되는지" 를 화면과 엑셀에서 바로 알 수 있게 한다.
NG 만 **한 엑셀 파일에 계속 누적** 저장한다. 리뷰어의 필요 없는 기능은 지운다.

```
날짜 폴더 열기 → cycle.json 로드
   └─ NG 사이클/측정마다 원인 규칙 평가 ─► 추정 원인 + 근거 숫자 + 확인할 일 1줄
          ├─ 리뷰어 화면: NG 행 선택 시 원인 표시
          └─ NG 누적 엑셀: 한 파일에 행 추가 (이미 들어간 사이클은 건너뜀)
```

## 확정 결정 (사용자, 2026-09-17)

| ID | 결정 |
|---|---|
| D-78-01 | **목적:** NG 가 나면 왜 났는지 분석. 기능의 가치는 "원인 추정" 이 핵심이고, 엑셀 저장·화면 표시는 그 결과를 전달하는 수단이다. |
| D-78-02 | **NG 만 엑셀 저장 + 누적 = 한 파일에 계속 쌓기.** 날짜와 상관없이 NG 분석 엑셀 파일 하나에 NG 행이 계속 추가된다. 이미 들어간 사이클은 중복으로 넣지 않는다. |
| D-78-03 | **원인 분석 = 규칙 기반 자동 판단.** 측정값·기준점·선택 Z·검출 실패 기록 등 저장된 데이터로 정해진 규칙을 평가한다. 장비 PC 에서 인터넷 없이 동작하고, 판단 근거 숫자를 같이 보여 준다. AI(외부 API) 사용 안 함. |
| D-78-04 | **결과 표시 = 화면 + 엑셀 둘 다.** 리뷰어에서 NG 행을 누르면 추정 원인이 보이고, NG 누적 엑셀에도 같은 내용이 열로 들어간다. |
| D-78-05 | **사용자는 비전 초보.** 문구는 쉬운 한국어, 전문용어 최소, 원인 1줄 + 근거 1줄 + "확인할 일" 1줄. (사용자: "결과 데이터 보고 하는 유저가 비전초짜이므로 쉽게") |
| D-78-06 | **리뷰어 기능 삭제 = "차트 이미지 캡처 점검" 버튼, "엑셀 export"(사이클 1건) 버튼.** 사이클 1건 export 는 NG 누적 export 로 대체. **유지:** 반복검사 묶음(자재번호 · 이전 결과에 누적 · 이미지 폴더 반복 검사 · 반복도 엑셀 export · CPK 리포트 export), Align 정합 조회. (사용자: "기존 리뷰어에서 필요없는 기능은 과감히 삭제") |
| D-78-07 | **리뷰어 사진 = 실제 촬영 사진 (O-78-06 확정).** 지금은 `ResultImagePath`(= 레시피 SimulImagePath)를 띄워 라이브 검사도 시뮬레이션 사진 위에 결과가 그려진다. NG 위치를 눈으로 확인하려면 그 검사의 실제 사진이 필요하므로 이번 phase 에 포함한다. 저장된 `OriginImageFileName` 을 우선 사용하고, 없을 때만 기존 경로로 폴백. |
| D-78-08 | **기준점 각도·원점·매칭 점수와 Z 후보별 선명도 점수를 cycle.json 에 추가 기록 (O-78-02 확정).** 지금은 Algorithm 로그에만 있어 리뷰어가 못 읽는다. 검사 로직·판정은 바꾸지 않고 기록만 추가한다. 옛 cycle.json(필드 없음)은 해당 규칙만 '데이터 없음' 으로 건너뛴다. |

<decisions>
위 표와 같은 내용 — GSD decision coverage gate 가 읽는 bullet 형식.

- **D-78-01:** 목적은 NG 가 나면 왜 났는지 분석하는 것. 원인 추정이 핵심, 엑셀·화면은 전달 수단.
- **D-78-02:** NG 만 엑셀로 저장하고 한 파일에 계속 누적한다. 이미 들어간 사이클은 중복으로 넣지 않는다.
- **D-78-03:** 원인 분석은 규칙 기반 자동 판단(오프라인, 근거 숫자 표시). 외부 AI 사용 안 함.
- **D-78-04:** 원인 결과는 리뷰어 화면(NG 행 선택 시)과 NG 누적 엑셀 둘 다에 보여 준다.
- **D-78-05:** 사용자는 비전 초보 — 쉬운 한국어, 원인 1줄 + 근거 1줄 + 확인할 일 1줄.
- **D-78-06:** 리뷰어에서 "차트 이미지 캡처 점검" 버튼과 사이클 1건 "엑셀 export" 버튼을 삭제한다. 반복검사 묶음과 Align 정합 조회는 유지한다.
- **D-78-07:** 리뷰어는 실제 촬영 사진(OriginImageFileName 우선, 없으면 기존 경로)을 띄운다. 이번 phase 에 포함.
- **D-78-08:** 기준점 각도·원점·매칭 점수와 Z 후보별 선명도 점수를 cycle.json 에 기록만 추가한다(검사 로직·판정 불변, 옛 파일 호환).
</decisions>

| # | 추정 원인 (화면 문구 예) | 판단 근거 (데이터) | 확인할 일 (예) |

| R7 | 한 곳만 벗어남 (실제 불량 또는 이물) | 같은 사이클에서 그 측정만 NG, 나머지는 정상 | 사진으로 해당 위치 확인, 실물 확인 |
| R8 | 초점 범위 부족 | 선택 Z 가 Z 범위의 **끝값** (정점이 범위 밖일 가능성) | PLC Z 범위를 넓혀 달라고 요청 (09-16 사례: 6개 전부 z5=끝값) |
