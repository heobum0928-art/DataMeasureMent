### Flagged assumptions (자동 해소 금지)
- **A-79-E1 (LSR-01 unclassified):** Local Ref 탭 구성(옵션 / ROI / Edge)과 첫 기준 ROI 를 숫자로 넣은 뒤 끌어 맞추는 방식이 운영자에게 쓸 만한지는 사람 판단 — 79-05 U-1.
- **A-79-E2 (LSR-02 unclassified):** z1 가로 사진에서 찾은 띠 위치를 측정 사진(z3~z9)의 핀과 같은 좌표로 쓴다. 같은 카메라·같은 사이클이라 전역 기준선도 이미 이렇게 쓰고 있지만(z1 사진 흔들림은 전역과 똑같이 남음 — CONTEXT 별건), 실제 사이클에서 성립하는지는 U-2·U-6 에서 확인.
- **A-79-E3 (LSR-03 unclassified):** 전환 로그 원인 문구와 표시 `국부실패→전역` 이 나중에 원인을 찾기에 충분한지 — U-3.
- **A-79-E4 (LSR-06 unclassified):** C13·C14 6점의 자재 A−B 편차가 전역보다 뚜렷이 줄어드는지(목표 수 µm)는 기준 ROI 창 선택에 좌우된다(RESEARCH Pitfall 1) — U-6 사용자 판단.
- **A-79-A1:** 기울기는 전역 각도 유지(P-5 (b)). 국부 기울기(a)가 더 나은지는 미검증.
- **A-79-A2:** P2 는 z1 사진에서 핀·띠 위치가 이번 조사로 확정되지 않았다(RESEARCH A5) — 79-05 realab 가 다시 재고, 안 잡히면 P2 는 켜지 않는 쪽을 UAT 에 적는다.
- **A-79-A3:** 사무실 PC 에는 TOP·BOTTOM 사진이 없다(레시피 SimulImagePath 폴더 부재 확인). TOP·BOTTOM 동작·전환은 공용 코드 경로라 구조로는 같지만 실제 확인은 장비 PC — U-7 backstop.
- **A-79-A4:** 옵션 꺼진 측정의 `기준` 칸은 빈칸(= 기존 전역). D-79-07 의 "전역" 표시를 빈칸으로 해석했다 — U-4 에서 사용자 확인.
- **A-79-A5:** 첫 기준 ROI 는 속성창 숫자 입력으로 만든다(CommitRectRoi 미변경). 불편하면 후속 quick 으로 그리기 경로를 더한다 — U-1.
- **A-79-A6:** Test Find 로 잡아 둔 기준점을 재사용하는 수동 RUN 은 Test Find 사진에서 구한 국부 기준선을 쓴다. 그 뒤 기준 ROI 를 고치면 다시 찾기 전까지 전환(원인 '설정이 바뀜') — U-3.
- **A-79-A7:** 화면(HalconDisplayService)의 국부 기준선은 주황이지만, 저장되는 캡처 사진(OverlayCaptureRenderer)은 색 표가 실측 RGB 8색 고정이라 바꾸지 않고 기존 '그 외' 색(파랑)으로 그려진다(79-03 이 OverlayCaptureRenderer 를 건드리지 않음). 거리선(청록)·에지선(녹/적)과는 구분된다 — U-4 에서 사용자 확인, 주황이 꼭 필요하면 후속 quick.
