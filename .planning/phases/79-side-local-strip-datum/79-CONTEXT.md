# Phase 79 — CONTEXT (결정 2026-09-17 ~ 09-18)

**사용자 원문 (2026-09-17): "이 검사 추가 우선 옵션으로 넣는거 가능한가?? 이거 되면 모든 검사에 넣으면 자재간 편차 줄일 수 있을꺼 같은데"**

SIDE 자재 간 측정 편차의 원인은 **금속 띠(기준선)가 휜 것**이다. 지금 기준선은 띠의 두 지점을
이은 직선이라 핀 위치의 실제 띠 높이를 따라가지 못한다. EdgeToLineDistance 에 **측정별 옵션**을
추가해, 측정과 같은 사진에서 **핀 바로 옆 띠**를 기준 ROI 로 찾고 그 선까지 거리를 잰다.

```
지금:    핀 에지 ──(수선)──► 전역 기준선 (Datum 가로선: 띠의 두 지점 col≈3140 · col≈10070 을 이은 직선)
옵션 ON: 핀 에지 ──(수선)──► 국부 기준선 (같은 사진, 핀 바로 옆 띠를 기준 ROI 에서 라인 피팅)
            └─ 기준 ROI 실패 시 ─► 전역 기준선으로 자동 전환 + 로그 (검사 계속)
```
