`InspectionListView.xaml.cs` 에 private 헬퍼 `ResolveActionIndexByShot(SequenceBase seq, ShotConfig target)` 를 추가한다.
반환은 `int`, 못 찾으면 -1. 구현은 `InspectionSequence.FindActionIndicesByZIndex`(InspectionSequence.cs L496-520)의
스캔 패턴을 그대로 미러링하되, `Actions` 는 protected 이므로 public 인덱서를 쓴다:
`for (int i = 0; i < seq.ActionCount; i++)` → `seq[i] as Action_FAIMeasurement` → null 이면 continue →
`ReferenceEquals(faiAct.ShotParam, target)` 이면 `i` 반환. `seq == null || target == null` 이면 즉시 -1.
브레이스는 이 파일의 K&R 스타일(여는 중괄호 같은 줄)에 맞춘다. InspectionSequence 의 Allman 스타일을 가져오지 말 것.

`ResolveRunnableAction`(L427~) 의 **Shot 노드 분기만** 교체한다 (`node.NodeType == ENodeType.Action && node.Param is ShotConfig shotCfg`):
1. `int idx = ResolveActionIndexByShot(seq, shotCfg);`
2. `idx >= 0` 이면 `actID = seq[idx].ID; return true;`
3. `idx < 0` 이고 `seqHandler.IsIdle` 이면 — "UI에서 Shot 추가 후 RebuildInspectionActions 미호출" 정상 케이스 —
   기존과 동일하게 `seqHandler.EnableDynamicFAIMode(); seqHandler.RebuildInspectionActions(seq.ID);` 호출 후
   **아이덴티티로 재스캔**하여 찾으면 `actID = seq[idx].ID; return true;`
4. 그래도 못 찾으면 `return false;`. **어떤 경우에도 서수 폴백을 두지 않는다.**

기존 L434-436 의 "글로벌 IndexOf 대신 로컬 인덱스" 주석은 더 이상 사실이 아니므로 삭제하고,
