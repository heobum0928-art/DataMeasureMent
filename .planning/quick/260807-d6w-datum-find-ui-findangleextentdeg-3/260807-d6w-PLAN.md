<objective>
Datum 패턴정렬(PatternAlign)의 **런타임 Find 각도 검색범위**를 PropertyGrid 설정값으로 승격한다.

사용자가 `PatternMatchService.cs` 에 직접 하드코딩해 둔 실험(±5°, `TupleGenConst`+`TupleRad(5,...)`)을
정식 설정 `DatumConfig.FindAngleExtentDeg`(기본 3, 단위 = 도, 의미 = ±N°)로 바꿔 배선하는 것이 전부다.

**왜 필요한가:** 원래 코드는 Find 를 항상 전방위(`-Math.PI, 2.0*Math.PI` = 360°)로 검색했다.
검색 각도 범위가 넓을수록 (a) 느리고 (b) 반복 feature 부품에서 엉뚱한 각도의 false match 가 잡힌다.
실제 장비의 부품 회전량은 몇 도 수준이라 ±3° 면 충분하다. 다만 이건 **레시피/부품마다 다른 튜닝값**이므로
하드코딩이 아니라 Datum 별 UI 설정이어야 한다.

**Output:**
- `DatumConfig.FindAngleExtentDeg` — PropertyGrid `Datum|PatternAlign` 카테고리 신규 항목, sentinel 0 → 3.0 복원
- `PatternMatchService.TryFindPose` / `TryFindRefPose` — 신규 **선택적** 파라미터 `double angleExtentDeg = 180.0`
- Datum 계열 Find 호출부 6곳 배선 (InspectionSequence 2 + MainView 4)
