## 절대 금지 (위반 시 즉시 중단)

1. **`WPF_Example/` 아래 어떤 파일도 수정/생성/삭제하지 않는다.** 소스 코드는 **읽기 전용**이다. Edit/Write 툴을 `WPF_Example/` 경로에 절대 사용하지 않는다.
2. **앱을 빌드하거나 실행하지 않는다.** 이 PC 는 실제 카메라/조명 컨트롤러(시리얼 포트)에 연결돼 있을 수 있다. `msbuild`, `dotnet build`, `DatumMeasurement.exe` 실행 금지. 화면 캡처도 하지 않는다.
3. **git commit 하지 않는다.** 커밋은 오케스트레이터가 나중에 처리한다.
4. **원본 매뉴얼 내용을 베끼지 않는다.** `_docx_text.txt` / `_pptx_text.txt` / `Equipment_Overview.md` 는 **장/절 번호 스타일과 문체 톤 참고용**으로만 본다. Wafer / Die / Map Matching / BIN / Scrib 같은 구형 설비 개념은 현재 시스템에 없으므로 절대 옮겨 적지 않는다.
5. **화면 문구를 지어내지 않는다.** 버튼명·메뉴명·컬럼명은 반드시 코드(XAML / `Resources.ko-KR.resx`)에서 실제로 확인한 문자열만 쓴다. 확인 못 한 항목은 문장을 만들지 말고 그 절을 빼거나 `[확인 필요]` 로 명시한다.
6. **민감정보를 문서에 싣지 않는다.** 실제 계정 ID/비밀번호, 비밀번호 해시, 내부 IP, 회사명/연락처를 임의로 적지 않는다. 회사 정보는 `[회사명]`, `[연락처]` 채움표로 남긴다. 계정은 "관리자에게 문의" 로만 안내한다.
