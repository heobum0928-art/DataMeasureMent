- `CPK_BAD_LIMIT = 1.0`, `CPK_WARN_LIMIT = 1.33` (double) — Cpk 1.0 미만 불량, 1.33 미만 주의.
- `MIN_SAMPLES_FOR_CPK = 2` (int) — 표본 1개 이하면 산포가 없어 Cpk 판정에 쓰지 않음.
- `CPK_SORT_INFINITE = double.MaxValue` — Cpk ∞(산포 0) 정렬 키: 모든 유한값 뒤.
- `CPK_SORT_NOT_COMPUTABLE = double.PositiveInfinity` — 계산불가 정렬 키: ∞ 보다도 뒤(맨 뒤).
- `VALUE_FORMAT = "F4"`, `CPK_FORMAT = "F3"`, `YIELD_FORMAT = "F2"`, `PERCENT_SCALE = 100.0`, `NO_VALUE_TEXT = "-"`.
- 벗어난 양 문자열 접두어 const: `UPPER_PREFIX = "상한 +"`, `LOWER_PREFIX = "하한 −"` (하한 쪽은 유니코드 마이너스 U+2212 문자, 요청 예시 "하한 −0.0032" 와 동일). 허용범위 구분자 `RANGE_SEPARATOR = " ~ "`.
