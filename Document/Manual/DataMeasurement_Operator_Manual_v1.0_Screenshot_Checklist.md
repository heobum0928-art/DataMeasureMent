# DataMeasurement 운영자 매뉴얼 — 스크린샷 캡처 체크리스트

이 목록은 `DataMeasurement_Operator_Manual_v1.0.docx` 안의 회색 자리표시자(그림 N-M)와 1:1로 대응합니다.

캡처가 끝나면 `.docx` 파일을 Word로 열어, 같은 번호가 적힌 회색 상자를 찾아 그 자리에 캡처한 이미지를 붙여넣으면 됩니다(회색 상자를 클릭해서 선택한 뒤 이미지로 교체).

캡처할 때 실제 계정 ID, 사번, 사내 IP, 실제 고객사 제품명 등 민감한 정보가 화면에 보이면 캡처 전에 가리거나, 캡처 후 모자이크 처리를 한 뒤 사용하십시오.

## 사전 준비

캡처를 시작하기 전에 아래 상태를 미리 만들어 두면 순서대로 진행하기 편합니다.

1. **레시피 준비** — 내용이 있는 정상 레시피 하나를 미리 불러와 둡니다. 2장, 4장, 5장, 6장 대부분의 그림이 이 상태를 전제로 합니다.
2. **로그인 계정 준비** — 관리자 또는 엔지니어 계정으로 로그인할 수 있어야 합니다. 3장은 로그인 전 → 로그인 시도 → 로그인 후 → 로그아웃 순서로 촬영해야 자연스럽습니다. 4-4, 7장(CAMERA/LIGHT/CONNECT)은 로그인한 상태여야 화면이 열립니다.
3. **검사 결과 준비** — 6장(결과 확인)을 캡처하려면 검사를 최소 1회 이상 실행해서 결과가 채워진 상태가 필요합니다. 가능하면 전 항목 합격 사례 1건, 불합격이 포함된 사례 1건을 각각 준비합니다. 불합격 사례를 실제로 재현하기 어려우면 과거에 저장된 결과 화면(결과 리뷰어)으로 대체해도 됩니다.
4. **과거 결과 데이터 준비** — 결과 리뷰어(6-5)와 통계분석(6-6) 화면은 과거에 저장된 결과가 있어야 목록/그래프가 채워집니다. 최근 검사 이력이 있는 상태에서 캡처합니다.
5. **9장(티칭) 캡처 준비** — 9장 캡처는 지금 진행 중인 실제 재티칭 작업을 하는 김에 순서대로 찍어 두는 것이 가장 쉽습니다. **캡처를 시작하기 전에 반드시 레시피 폴더를 백업하십시오**(9-1절 "재티칭 전 레시피 폴더 전체 백업" 참고). Bottom 화면(9-5)은 슬롯을 하나씩 바꿔가며 촬영해야 6개 슬롯 관련 그림을 채울 수 있습니다.

**로그인이 필요 없는 화면**: 2장 전체, 4-1 ~ 4-3, 5장 전체, 6장 전체, 8장 전체 (그림 1-1 제외, 이 그림은 장비 외관 사진이라 프로그램 로그인과 무관).

**로그인이 필요한 화면**: 3-3, 3-4(로그인 후 상태 확인용), 4-4, 7-1, 7-2, 7-3, 7-4, 9-2, 9-3(Datum · 패턴 편집 — 왼쪽 속성 편집 영역이 로그인해야 활성화됨. 레시피 [COPY] / [Delete]는 Admin 등급 필요). 9-4 / 9-5(Align 화면)는 로그인 여부와 관계없이 조작할 수 있습니다.
